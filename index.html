Devion · by San Ju

Devion — a free-model AI coding agent for Windows Developed, made and owned by San Ju, a Filipino developer. Devion is an independent desktop app and has nothing to do with Devin.ai.

Devion reads and writes real files, runs real commands, verifies its own work, and runs on free web models instead of a subscription — no API key needed to start.

What it does

  • Picks the strongest reachable free model for each task, and hands over silently when one stops answering.
  • Full access to the machine it runs on: any path, any command, any app.
  • Drives the tools already installed — VS Code, Notepad++, Git Bash, PowerShell, cmd — and opens files at the exact line it changed.
  • Real project awareness: codebase search, references, diffs, undo of a whole turn, and a verify step that runs the project's own tests.
  • Authorized security checks (HTTP headers, TLS certificate, open TCP ports) restricted to hosts you list yourself.
  • Ships as one double-clickable .exe. No Docker, no config, no account.

Who makes it
